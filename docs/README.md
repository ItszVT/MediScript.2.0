# MediScript documentation

Three guides, from quickest to deepest:

1. **MediScript-Quick-Reference.pdf** — one printable page. "I want to change X →
   open this file", the everyday commands, and how to add medicines fast.

2. **MediScript-Editing-Guide.pdf** — friendly starter for changing text, colours,
   menus and pages by hand. No code knowledge needed.

3. **MediScript-Developer-and-Data-Guide.pdf** — the deep companion: every folder
   explained, the OCR→detect→match pipeline, how to extend the medicine datasets,
   references (services / API / database / config), walkthroughs, and future ideas.

See also the top-level **README.md** (project overview) and **DEPLOY.md**
(free-tier Render deployment).
